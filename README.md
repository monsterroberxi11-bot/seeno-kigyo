# 🎲 せーの！起業ダイス

みんなで「せーの」で業界を選んで、ダイスを振ってお金をかせぐブラウザゲームです。中学生が作りました。

**▶ 遊ぶ：https://monsterroberxi11-bot.github.io/seeno-kigyo/**

## あそびかた

- 🤖 **ひとりで**：CPUと対戦
- 👨‍👩‍👧 **この端末でみんなで**：1台を交代で使う（選ぶときはほかの人に見えない画面になる）
- 🌐 **オンライン**：4けたの部屋コードで友だちと対戦（最大6人、空いた席はCPU）

## ルール

1. **スキルカードを買う**：山札から1人3枚ずつ配られる。お金が足りれば全部買える。持てるのは5枚まで
2. **せーので業界を選ぶ**：業界カードは参加人数と同じ枚数。誰ともかぶらなければダイスをひとりじめ、かぶったら親に近い人から1個ずつ
3. **ダイスを振る**：出目の合計＋スキルカードの効果がもらえるお金。マイナスなら払う
4. **業界の入れかえ**：親が選んだ業界が新しい業界に入れかわって、親が次の人へ

3ラウンドごとに📉不況（お金が多い人ほど取られて、みんなのスキルカードをシャッフルして配り直し）か📈好況（全員にお金とカード1枚）が起きます。オレンジの企業カードを場に出すと、そのラウンドだけの業界がふえます。

12ラウンドでお金が一番多い人の勝ち！

紫の使い切りカードは、手札からドラッグして場に出すと使えます。カードは🔍で大きくして説明を読めます。

## つくり

`index.html` 1ファイルだけ。オンライン対戦は [PeerJS](https://peerjs.com/) を使っています。
